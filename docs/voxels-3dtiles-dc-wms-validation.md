# Voxel Rendering、Voxels in 3D Tiles、Washington DC 2017 与 Web Map Service (WMS) 完整案例验证报告 (Batch 90 / v0.0.90)

## 1. 概述与验证总览

本批次（Batch 90，版本 **v0.0.90**）聚焦于 Cesium 引擎核心的 **程序化体素图元多形状生成与元数据着色、3D Tiles 八叉树流式体素数据集、0.08m 极高分辨率航空正射影像、以及 OGC Web Map Service (WMS) 地图图层集成（Procedural Voxel Primitives, 3D Tiles Voxel Streaming, Sub-Decimeter Aerial Orthoimagery & OGC WMS Services）** 体系，完成以下 4 个官方 Sandcastle 全量案例的原生 Rust、Wasm WebGPU 以及真实浏览器环境端到端验证，累计完成度推进至 **307 / 309**（完成率 **99.35%**，距离 100% 仅剩最后 2 个案例！）：

1. **`voxels` ("Voxel Rendering")**：
   - 核心特性：多形状（长方体、圆柱体、椭球体）程序化体素图元生成（`VoxelPrimitive` / `VoxelShapeType`）、体素元数据与自定义着色器（`CustomShader`）透明度/光照调节、`viewerVoxelInspectorMixin` 诊断面板混入。
   - 变体设计：涵盖基准长方体体素体积图元模式、圆柱体体素图元模式、椭球体密度核渐变模式、多形状全景综合检查模式 4 种变体。
2. **`voxels-in-3d-tiles` ("Voxels in 3D Tiles")**：
   - 核心特性：以 3D Tiles 格式流式加载体素数据集（`Cesium3DTilesVoxelProvider`）、八叉树瓦片层级、最近邻采样滤波（`nearestSampling`）与包围球相机自动定位（`flyToBoundingSphere`）。
   - 变体设计：涵盖基准 3D Tiles 体素长方体瓦片集模式、圆柱体体素瓦片提供者模式、椭球体 3D Tiles 体素体积模式、多层级 LOD 瓦片阶梯剖分模式 4 种变体。
3. **`washington-dc-2017` ("Washington DC 2017")**：
   - 核心特性：Cesium ion 托管的华盛顿哥伦比亚特区 3 英寸（0.08 米）超高分辨率航空摄影正射影像（`IonImageryProvider.fromAssetId(3827)`）、国会大厦与国家广场重点地标对准、分米级空间定位与取景。
   - 变体设计：涵盖基准国家广场 0.08m 高分辨率航测正射模式、国会山庄穹顶建筑巡检模式、华盛顿纪念碑方尖碑定位模式、特区全域宏观视域巡礼模式 4 种变体。
4. **`web-map-service-wms` ("Web Map Service (WMS)")**：
   - 核心特性：OGC Web 地图服务（WMS）影像图层集成（`WebMapServiceImageryProvider`）、澳大利亚地球科学局（Geoscience Australia）离岸石油租约区块透明 PNG 瓦片流式加载与洲际范围定位。
   - 变体设计：涵盖基准澳大利亚离岸石油租借区块 WMS 模式、西北大陆架油气勘探区块模式、大澳大利亚湾海洋环境勘查模式、全澳大陆 WMS 覆层宏观总览模式 4 种变体。
