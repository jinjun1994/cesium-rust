# 第三方与规范

依赖的精确版本见 Cargo.lock：wgpu 30.0.1（MIT/Apache-2.0）、naga 30.0.0（MIT/Apache-2.0）、glam 0.30.9（MIT/Apache-2.0）、gltf 1.4.1（MIT/Apache-2.0）、winit 0.30.12（Apache-2.0）、serde / serde_json（MIT/Apache-2.0）、bytemuck（Zlib/Apache-2.0/MIT）、url（MIT/Apache-2.0）、reqwest（MIT/Apache-2.0）、wasm-bindgen（MIT/Apache-2.0）。请发布前用许可证工具按完整锁文件复核所有传递依赖。

工程没有集成 Cesium Native FFI、Draco 或 Basis 编解码器。不宣称完整依赖链没有 C/C++：图形驱动、操作系统以及 reqwest TLS 依赖的实现来源需独立审计。

测试资产 triangle / sparse / stride 及 b3dm 为本工程生成，不包含外部商业模型或地图数据。Playwright 只用于开发测试，不属于运行时引擎依赖。

规范依据：

- [OGC 3D Tiles 1.1](https://docs.ogc.org/cs/22-025r4/22-025r4.html)
- [glTF 2.0](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html)
- [wgpu 30.0.1](https://docs.rs/wgpu/30.0.1/wgpu/)
- [WGSL](https://www.w3.org/TR/WGSL/)

完整实施方案保留在 implementation-plan.md；上述 crate 仅实现 capabilities.json 声明的子集。

## Specification references for 0.0.5

- glTF 2.0: https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html
- 3D Tiles 1.1: https://github.com/CesiumGS/3d-tiles/blob/main/specification/README.adoc

The new material fixtures are generated by this project, contain no external imagery, and exercise the core material channels. Neither the shader's derivative tangent fallback nor its directional/ambient lighting is a complete glTF conformance or physical-lighting implementation.

## GeoJSON additions

- GeoJSON coordinates and geometry definitions: RFC 7946, https://www.rfc-editor.org/rfc/rfc7946 . Implementation is a bounded rendering subset, not complete conformance.
- Polygon triangulation uses earcutr 0.4.3 (ISC license), https://crates.io/crates/earcutr . Its transitive dependencies are retained in Cargo.lock.
- GeoJSON demo features are synthetic project-generated data and do not represent administrative boundaries or a navigation route.

公开高程来自 Mapzen / Tilezen Terrain Tiles，访问于 2026-10-13： https://registry.opendata.aws/terrain-tiles/ 。来源与各数据许可证见 terrain-attribution.md。测试夹具保留 URL、SHA-256 于 tests/fixtures/terrain/provenance.json。官方 quantized-mesh 样本来自 CesiumGS/cesium 的 Specs/Data/CesiumTerrainTileJson，许可证见 cesium-terrain-fixtures-LICENSE.md。离线 demo 由本项目生成，不代表真实地形。
